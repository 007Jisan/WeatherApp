# 🌤️ WeatherApp

A clean, responsive, and interactive weather application built with vanilla web technologies. This app dynamically fetches real-time weather data using a third-party Weather API, allowing users to instantly check current weather conditions, temperature, and forecasts.

## ✨ Features
* **Real-Time Data:** Fetches and displays accurate, up-to-date weather information based on user input.
* **API Integration:** Seamlessly integrates with a Weather API (RESTful API) to retrieve asynchronous location-based data.
* **Responsive Design:** Fully optimized for seamless viewing across both desktop and mobile devices.
* **User-Friendly Interface:** Clean, intuitive, and minimalistic UI built entirely with custom CSS.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Data Source:** Weather API *
* **Deployment:** Hosted live on GitHub Pages
